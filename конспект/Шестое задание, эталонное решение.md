## Условие

- Обучите модель линейной регрессии на числовых признаках и оцените её качество через MAPE и RMSE.
- Сделайте вывод о качестве построенной модели.

## Что сделано в эталоне

### Шаг 1. Обучили модель и посчитали метрики

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_percentage_error, root_mean_squared_error

model = LinearRegression()
model.fit(X_train_numerical, y_train)

y_pred = model.predict(X_test_numerical)

mape = mean_absolute_percentage_error(y_test, y_pred)
rmse = root_mean_squared_error(y_test, y_pred)

print(f'MAPE: {mape}')
print(f'RMSE: {rmse}')
```

Разбор:
1. `LinearRegression()` — создаём пустую модель.
2. `fit(X_train_numerical, y_train)` — обучаем на train, только на числовых признаках из задания 5 (`work_year`, `remote_ratio`).
3. `predict(X_test_numerical)` — предсказываем зарплаты для теста.
4. Сравниваем предсказания `y_pred` с правильными ответами `y_test` двумя метриками.

Вывод ячейки:

```
MAPE: 0.706483138102007
RMSE: 61358.93909117817
```

То есть **MAPE ≈ 70.6%**, **RMSE ≈ 61 359 USD**.

### Что значат метрики

- **MAPE** (средняя абсолютная процентная ошибка) — на сколько процентов в среднем модель ошибается относительно настоящей зарплаты. 0.706 = промах в среднем на 70%.
- **RMSE** (корень из средней квадратичной ошибки) — типичная ошибка в долларах. Сильно «штрафует» большие промахи.

Внимание: `MAPE` в sklearn возвращается долей (0.706), а не процентами. Чтобы напечатать проценты, пишут `f'{mape:.2%}'`.

### Шаг 2. График «факт vs предсказание»

```python
plt.scatter(y_test, y_pred, alpha=0.5)
plt.plot([y_test.min(), y_test.max()], [y_test.min(), y_test.max()], 'r--')
plt.xlabel('Фактические значения (y_test)')
plt.ylabel('Предсказанные значения (y_pred)')
plt.title(f'Фактические vs Предсказанные\nMAPE: {mape:.2%}, RMSE: {rmse:.2f}')
plt.grid(True)
plt.show()
```

Каждая точка — один объект из теста: по X настоящая зарплата, по Y предсказанная. Красная пунктирная диагональ — идеальная модель (предсказание = факт). Чем дальше точки от диагонали, тем хуже.

### Шаг 3. График остатков

```python
residuals = y_test - y_pred

plt.scatter(y_pred, residuals, alpha=0.5)
plt.hlines(0, y_pred.min(), y_pred.max(), colors='r', linestyles='--')
plt.xlabel('Предсказанные значения (y_pred)')
plt.ylabel('Остатки (y_test - y_pred)')
plt.title('График остатков')
plt.grid(True)
plt.show()
```

Остаток = факт − предсказание. Положительный остаток — модель недооценила, отрицательный — переоценила. У хорошей модели точки равномерно лежат вокруг нуля без явной структуры.

### Выводы эталона (пересказ ячейки 48)

1. **MAPE ≈ 70%** — очень плохо для регрессии. Модель промахивается на половину–две трети реальной зарплаты. Данные, которые видит модель, плохо объясняют `salary_in_usd`, важные признаки не учтены.
2. **RMSE ≈ 61 359 USD** — при средней зарплате порядка 100–150 тыс. USD ошибка в 61 тыс. огромная.
3. **По графику остатков:** модель выдаёт предсказания только на нескольких уровнях, а остатки сильно разбросаны. Линейная зависимость между выбранными признаками и зарплатой неадекватна.

## Что в эталоне недосказано (стоит понимать самому)

1. **Почему предсказания «на нескольких уровнях».** У модели всего два входа: `work_year` (4 значения) и `remote_ratio` (3 значения). Комбинаций максимум 12, значит, и разных предсказаний не больше 12. Модель физически не может выдать что-то разнообразнее.
2. **Почему MAPE такой большой.** MAPE делит ошибку на настоящую зарплату. На низких зарплатах (например, 15 тыс.) промах в 60 тыс. даёт ошибку 400%, и такие строки сильно тянут среднее вверх. RMSE, наоборот, больше всего портят очень высокие зарплаты. Поэтому смотрят обе метрики.
3. **Полезно сравнить с простейшим ориентиром.** Например, предсказывать всем среднюю зарплату из train и посчитать те же метрики. Если модель не сильно лучше среднего, она почти ничего не выучила. В эталоне такого сравнения нет.
4. **Метрики считаются только на тесте.** Модель обучена на train, а оценка — на `X_test_numerical` / `y_test`, которые она не видела.

## Правило на будущее

- Схема любой модели в sklearn: `model = ...()` → `model.fit(X_train, y_train)` → `y_pred = model.predict(X_test)` → метрика `(y_test, y_pred)`.
- В метрики первым передаём правильные ответы, вторым — предсказания.
- Для регрессии смотрим минимум две метрики: относительную (MAPE) и в единицах цели (RMSE).
- Кроме чисел, строим два графика: «факт vs предсказание» и остатки. Они показывают, **где** модель ошибается.
- Ошибку оцениваем относительно масштаба цели: 61 тыс. USD много при зарплатах в 100–150 тыс.
