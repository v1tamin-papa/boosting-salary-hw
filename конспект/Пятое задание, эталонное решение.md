## Условие

Будем проверять два сценария:
1. модель только на непрерывных (числовых) признаках;
2. модель на непрерывных + категориальных признаках.

Нужно подготовить данные для обоих сценариев:
- выделить train и test для непрерывных признаков;
- выделить train и test для непрерывных + категориальных признаков, **пока ничего не кодируя**.

---

## Что сделано в эталоне

### Шаг 1. Посмотрели, какие колонки числовые

```python
list(df.select_dtypes(include='number').columns)
```

`select_dtypes(include='number')` оставляет только колонки с числами (int, float). После задания 3 (удалили `salary`) это:
- `work_year`
- `remote_ratio`
- `salary_in_usd` — целевая, её в признаки брать нельзя.

### Шаг 2. Собрали оба набора данных

```python
# Выделяем непрерывные признаки
numerical_features = list(df.select_dtypes(include='number').columns)
numerical_features.remove('salary_in_usd')

X_train_numerical = X_train[numerical_features]
X_test_numerical = X_test[numerical_features]

# Выделяем данные для тренировки и теста для непрерывных + категориальных признаков
X_train_all = X_train
X_test_all = X_test
```

Разбор:
1. `numerical_features` — список числовых колонок без целевой: `['work_year', 'remote_ratio']`.
2. **Сценарий 1 (только числа):** из уже готовых `X_train` и `X_test` (задание 4) берём только эти 2 колонки.
3. **Сценарий 2 (числа + категории):** берём `X_train` и `X_test` целиком — все 8 признаков, текст остаётся текстом.
4. Новое разбиение на train/test **не делаем**: оба сценария используют одно и то же разбиение из задания 4. `y_train` и `y_test` тоже общие.

### Что получается

| Набор | Колонки | Строк |
|---|---|---|
| `X_train_numerical` / `X_test_numerical` | `work_year`, `remote_ratio` | ≈3004 / ≈751 |
| `X_train_all` / `X_test_all` | все 8 признаков | ≈3004 / ≈751 |

---

## Что в эталоне недосказано (стоит понимать самому)

1. **Почему важно одно и то же разбиение.** Сравнивать сценарии честно можно, только если модели проверяются на одних и тех же строках теста. Если разбить заново, разница в метриках может оказаться случайностью разбиения, а не эффектом признаков.
2. **Числовых признаков всего два.** `work_year` — по сути год (4 значения), `remote_ratio` — три значения (0, 50, 100). Это скорее категории, записанные числами.
3. **`X_train_all = X_train` — это не копия, а та же таблица.** Если потом изменить `X_train_all` на месте (например, добавить колонку), изменится и `X_train`. Безопаснее писать `X_train.copy()`.
4. **Слово «непрерывные» здесь условное.** Эталон отбирает признаки по типу данных (число / не число), а не по смыслу.

---

## Правило на будущее

- Числовые колонки быстро отбираются через `df.select_dtypes(include='number')`, текстовые — через `include='object'`.
- Целевую колонку всегда убираем из списка признаков.
- Для сравнения нескольких вариантов модели используем одно разбиение train/test.
- Если таблицу будем менять, делаем `.copy()`, чтобы не испортить исходную.
